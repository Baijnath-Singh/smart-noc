# Archive

This directory contains historical documents that are no longer actively maintained but preserved for reference.

## 📁 What's Here

### `/phase-history/`
**Implementation phases** from project development:
- PHASE0-PHASE4 documents showing system evolution
- Each phase had specific goals and deliverables
- Useful for understanding architectural decisions

**Why archived?** System is now in production; phase-based development complete.

### `/week-progress/`
**Weekly progress reports** from development sprints:
- WEEK1, WEEK2 status updates
- Feature completion milestones
- Integration progress

**Why archived?** Development period complete; weekly tracking no longer needed.

### `/obsolete-guides/`
**Superseded documentation** replaced by newer versions:
- Old architecture documents (merged into current)
- Deprecated implementation approaches
- Replaced guides and references

**Why archived?** Content superseded by updated documentation in main folders.

### `/exercise-analysis/`
**Exercise-specific documents** from development exercises:
- Exercise alignment analysis
- Flow analysis examples
- Training materials

**Why archived?** Exercise-specific; not relevant to production operations.

## 📜 Archive Policy

### When Documents Are Archived

1. **Development Complete**: Implementation phases finished
2. **Superseded**: Newer version exists in active docs
3. **Historical Value**: Important for context but not current operations
4. **Exercise-Specific**: Relevant only to specific training/development exercises

### Archive Format

Archived documents include:
- **Date archived**: When moved to archive
- **Reason**: Why it was archived
- **Replacement**: Link to current equivalent (if applicable)
