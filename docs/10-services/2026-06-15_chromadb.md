# ChromaDB Vector Database

**Service Name:** `smart-noc-chromadb`  
**Image:** `chromadb/chroma:0.5.0`  
**Technology:** ChromaDB 0.5.0 (Vector Database)  
**Status:** Infrastructure (AI/ML)  
**Uptime Target:** 99.5%

## Overview

ChromaDB is the **knowledge base storage** for Smart NOC, providing vector similarity search for retrieving relevant historical incidents and remediation knowledge during LLM diagnosis.

## Vector Search

### Query Process

**Step 1: Client Builds Query**
```python
query_text = f"""
Incident Type: CONNECTIVITY_ISSUE
Device: extreme exos
Symptoms: INTERFACE_FLAPPING
Interface: 1:55
"""
```

**Step 2: Vector Search API Call**
```python
import chromadb
client = chromadb.HttpClient(host="chromadb", port=8000)
collection = client.get_collection("kb_articles")

results = collection.query(
    query_texts=[query_text],
    n_results=5,
    where={"vendor": "extreme", "platform": "exos"},
    include=["metadatas", "documents", "distances"]
)
```

**Step 3: Results Ranked by Similarity**
```python
{
    "ids": [["EXT-EXOS-001", "EXT-EXOS-012", ...]],
    "distances": [[0.23, 0.35, 0.42, ...]],  # Lower = more similar
    "metadatas": [[{
        "id": "EXT-EXOS-001",
        "title": "EXOS Interface Flapping Due to Cable Issues",
        "vendor": "extreme",
        "platform": "exos"
    }, ...]],
    "documents": [["Full article text...", ...]]
}
```

**Step 4: LLM Context Building**
- Top 5 most similar articles included in LLM prompt
- Articles provide vendor-specific commands and remediation steps
- Distance threshold: <0.5 (highly similar), 0.5-0.8 (relevant), >0.8 (not relevant)

## Adding Knowledge Base Articles

### Python API
```python
import chromadb
from sentence_transformers import SentenceTransformer

client = chromadb.HttpClient(host="chromadb", port=8000)
collection = client.get_or_create_collection("kb_articles")

# Article content
article_text = """
Title: EXOS Interface Flapping Due to Cable Issues
Symptoms: Port repeatedly transitions between UP and DOWN states...
"""

# Metadata
metadata = {
    "id": "EXT-EXOS-001",
    "title": "EXOS Interface Flapping Due to Cable Issues",
    "vendor": "extreme",
    "platform": "exos",
    "event_type": "interface_down",
    "severity": "HIGH"
}

# Add to collection
collection.add(
    documents=[article_text],
    metadatas=[metadata],
    ids=["EXT-EXOS-001"]
)
```

## Troubleshooting

### Issue: No Results Returned

**Symptoms:**
- Query returns empty results
- Distance scores all >0.8

**Diagnosis:**
```python
# Check collection count
collection = client.get_collection("kb_articles")
print(f"Documents: {collection.count()}")

# Test simple query
results = collection.query(query_texts=["interface"], n_results=5)
```

**Resolution:**
1. Verify articles exist in collection
2. Check metadata filters (e.g., vendor, platform)
3. Broaden query (remove specific filters)

---

### Issue: Slow Query Performance

**Symptoms:**
- Queries taking >500ms
- LLM diagnosis delayed

**Diagnosis:**
- Check collection size (>10K documents may need indexing)
- Monitor CPU usage during queries

**Resolution:**
1. Enable HNSW indexing (faster approximate search)
2. Reduce `n_results` (5 → 3)
3. Cache frequent queries in Redis
