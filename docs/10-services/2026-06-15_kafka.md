# Kafka Message Broker

**Service Name:** `smart-noc-kafka`  
**Image:** `apache/kafka:3.7.0`  
**Technology:** Apache Kafka 3.7.0  
**Status:** Core Infrastructure  
**Uptime Target:** 99.99%

---

## Overview

Apache Kafka is the **event streaming backbone** of Smart NOC, enabling real-time data flow between all services. It provides durable, scalable, and fault-tolerant message passing for the entire pipeline.

---

## Service Configuration

### Ports
- **9092:** Kafka broker (internal)
- **9093:** Kafka broker (external/monitoring)

### Resources
- **Memory:** 2GB-4GB
- **CPU:** 2 cores
- **Storage:** 20GB-100GB (message retention)

### Environment Variables
```
KAFKA_BROKER_ID: 1
KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
KAFKA_LISTENERS: PLAINTEXT://0.0.0.0:9092
KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
KAFKA_LOG_RETENTION_HOURS: 168  # 7 days
KAFKA_AUTO_CREATE_TOPICS_ENABLE: true
```

## Kafka Topics

### 1. **network-logs**

**Purpose:** Enriched syslog messages from Logstash  
**Partitions:** 3  
**Replication Factor:** 1  
**Retention:** 7 days  

**Producer:** Logstash  
**Consumer:** Anomaly Detector

**Message Schema:**
```json
{
  "@timestamp": "2026-06-13T22:51:55.123Z",
  "device_id": "10.139.38.188",
  "syslog_message": "Port 1:55 link DOWN",
  "event_type": "INTERFACE_DOWN",
  "interface": "1:55",
  "device_vendor": "Extreme Networks",
  "device_family": "EXOS",
  "device_cli_syntax": "EXOS",
  "device_role": "core"
}
```

**Throughput:** 1,000-10,000 messages/second  
**Avg Message Size:** 500 bytes

## Topic Management

### Create Topic
```bash
docker exec smart-noc-kafka kafka-topics.sh \
  --create \
  --bootstrap-server localhost:9092 \
  --topic network-logs \
  --partitions 3 \
  --replication-factor 1
```

### List Topics
```bash
docker exec smart-noc-kafka kafka-topics.sh \
  --list \
  --bootstrap-server localhost:9092
```

### Describe Topic
```bash
docker exec smart-noc-kafka kafka-topics.sh \
  --describe \
```

## Consumer Groups

### Active Consumer Groups
- **anomaly-detector-group:** Consumes `network-logs`
- **correlation-engine-group:** Consumes `anomalies`
- **llm-diagnosis-group:** Consumes `incidents`
- **remediation-agent-group:** Consumes `incidents-diagnosed`

### Monitor Consumer Lag
```bash
docker exec smart-noc-kafka kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 \
  --group anomaly-detector-group \
  --describe
```

**Output:**
```
GROUP                 TOPIC         PARTITION  CURRENT-OFFSET  LOG-END-OFFSET  LAG
anomaly-detector-group network-logs  0         12543          12543           0
anomaly-detector-group network-logs  1         12489          12489           0
anomaly-detector-group network-logs  2         12501          12501           0
```

**Healthy:** LAG = 0 (consumers keeping up)  
**Unhealthy:** LAG >1000 (consumers falling behind)

## Performance Tuning

### Producer Configuration
```python
producer = KafkaProducer(
    bootstrap_servers=['kafka:9092'],
    acks=1,  # Leader acknowledgment (balance durability/performance)
    compression_type='snappy',  # Reduce network bandwidth
    batch_size=16384,  # Batch messages for efficiency
    linger_ms=10  # Wait up to 10ms to fill batch
)
```

### Consumer Configuration
```python
consumer = KafkaConsumer(
    'network-logs',
    bootstrap_servers=['kafka:9092'],
    group_id='anomaly-detector-group',
    auto_offset_reset='latest',  # Start from newest messages
    enable_auto_commit=True,  # Auto-commit offsets
    auto_commit_interval_ms=5000,  # Commit every 5 seconds
    max_poll_records=500  # Fetch up to 500 messages per poll
)
```

## Troubleshooting

### Issue: Consumer Lag Growing

**Diagnosis:**
```bash
docker exec smart-noc-kafka kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 \
  --describe \
  --all-groups | grep LAG
```

**Resolution:**
1. Scale consumers (add more instances)
2. Increase consumer batch size
3. Optimize consumer processing logic

---

### Issue: Disk Space Full

**Diagnosis:**
```bash
docker exec smart-noc-kafka df -h /var/lib/kafka
```

**Resolution:**
1. Reduce retention: `KAFKA_LOG_RETENTION_HOURS=24`
2. Enable compression: `compression.type=snappy`
3. Add more disk space to Kafka volume
