# PostgreSQL Database

**Service Name:** `smart-noc-postgres`  
**Image:** `postgres:16-alpine`  
**Technology:** PostgreSQL 16  
**Status:** Core Infrastructure  
**Uptime Target:** 99.99%

---

## Overview

PostgreSQL is the **persistent data store** for Smart NOC, storing device inventory, incidents, anomalies, and all historical data for analysis and reporting.

## Database Schema

### 1. **devices**

**Purpose:** Device inventory with enrichment metadata

```sql
CREATE TABLE devices (
    device_id VARCHAR(100) PRIMARY KEY,
    management_ip INET UNIQUE NOT NULL,
    vendor VARCHAR(100),
    device_family VARCHAR(100),
    model VARCHAR(200),
    os_version VARCHAR(50),
    cli_syntax VARCHAR(50),
    device_role VARCHAR(50),
    site VARCHAR(100),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_devices_management_ip ON devices(management_ip);
CREATE INDEX idx_devices_vendor ON devices(vendor);
```

**Example Data:**
```sql
INSERT INTO devices VALUES (
    '10.139.38.188',
    '10.139.38.188'::inet,
    'Extreme Networks',
    'EXOS',
    'X690-48x (2-slot stack)',
    '32.6.1.2',
    'EXOS',
    'core',
    'datacenter-1',
    NOW(),
    NOW()
);
```

**Row Count:** Thousands (one per managed device)

### 2. **incidents**

**Purpose:** Main incident tracking table

```sql
CREATE TABLE incidents (
    incident_number SERIAL PRIMARY KEY,
    incident_type VARCHAR(100),
    device_id VARCHAR(100) REFERENCES devices(device_id),
    severity VARCHAR(20),
    status VARCHAR(50),
    anomaly_count INTEGER,
    first_anomaly_time TIMESTAMP,
    last_anomaly_time TIMESTAMP,
    root_cause TEXT,
    remediation_plan TEXT,
    confidence_score FLOAT,
    assigned_to VARCHAR(100),
    resolved_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_incidents_device_id ON incidents(device_id);
CREATE INDEX idx_incidents_status ON incidents(status);
CREATE INDEX idx_incidents_severity ON incidents(severity);
CREATE INDEX idx_incidents_created_at ON incidents(created_at DESC);
```

**Status Values:**
- `PENDING_DIAGNOSIS`: Waiting for LLM analysis
- `DIAGNOSED`: Root cause identified, remediation plan ready
- `IN_PROGRESS`: Remediation being executed
- `RESOLVED`: Incident closed successfully
- `ESCALATED`: Manual intervention required

**Example Query:**
```sql
SELECT incident_number, device_id, incident_type, severity, status
FROM incidents
WHERE status = 'DIAGNOSED'
  AND severity IN ('HIGH', 'CRITICAL')
ORDER BY created_at DESC
LIMIT 10;
```

**Row Count:** Hundreds per day, millions over time

### 3. **incident_anomalies**

**Purpose:** Link anomalies to incidents (many-to-one)

```sql
CREATE TABLE incident_anomalies (
    id SERIAL PRIMARY KEY,
    incident_number INTEGER REFERENCES incidents(incident_number),
    anomaly_id VARCHAR(100),
    anomaly_type VARCHAR(50),
    anomaly_data JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_incident_anomalies_incident ON incident_anomalies(incident_number);
CREATE INDEX idx_incident_anomalies_anomaly_id ON incident_anomalies(anomaly_id);
```

**Example Data:**
```sql
INSERT INTO incident_anomalies (incident_number, anomaly_id, anomaly_type, anomaly_data)
VALUES (
    20024,
    'anom-20240613-001',
    'INTERFACE_FLAPPING',
    '{"interface":"1:55","event_count":4,"device_vendor":"Extreme Networks"}'::jsonb
);
```

**Row Count:** 2-10 per incident

### 4. **anomalies**

**Purpose:** Historical anomaly log

```sql
CREATE TABLE anomalies (

    severity VARCHAR(20),

    event_count INTEGER,

CREATE INDEX idx_anomalies_device_id ON anomalies(device_id);
CREATE INDEX idx_anomalies_type ON anomalies(anomaly_type);
CREATE INDEX idx_anomalies_created_at ON anomalies(created_at DESC);
```

**Row Count:** Thousands per day

**Purpose:** Track LLM performance, debugging, compliance

---

### 6. **remediation_actions**

**Purpose:** Track all remediation attempts

```sql
CREATE TABLE remediation_actions (
    action_id SERIAL PRIMARY KEY,
    incident_number INTEGER REFERENCES incidents(incident_number),
    device_id VARCHAR(100),
    command TEXT,
    execution_mode VARCHAR(50),
    status VARCHAR(50),
    output TEXT,
    error_message TEXT,
    executed_at TIMESTAMP,
    executed_by VARCHAR(100),
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_remediation_actions_incident ON remediation_actions(incident_number);
CREATE INDEX idx_remediation_actions_device ON remediation_actions(device_id);
```

**Status Values:**
- `SIMULATED`: Command logged (simulation mode)
- `PENDING_APPROVAL`: Awaiting human approval
- `APPROVED`: Approved for execution
- `EXECUTED`: Successfully executed
- `FAILED`: Execution failed
- `ROLLED_BACK`: Rolled back after failure

## Common Queries

### Active Incidents
```sql
SELECT 
    i.incident_number,
    i.device_id,
    d.vendor,
    d.model,
    i.incident_type,
    i.severity,
    i.status,
    COUNT(ia.anomaly_id) as anomaly_count,
    i.created_at
FROM incidents i
LEFT JOIN devices d ON i.device_id = d.device_id
LEFT JOIN incident_anomalies ia ON i.incident_number = ia.incident_number
WHERE i.status IN ('PENDING_DIAGNOSIS', 'DIAGNOSED', 'IN_PROGRESS')
GROUP BY i.incident_number, d.vendor, d.model
ORDER BY i.created_at DESC;
```

### Incident Resolution Time (MTTR)
```sql
SELECT 
    AVG(EXTRACT(EPOCH FROM (resolved_at - created_at))/60) as avg_resolution_minutes,
    COUNT(*) as total_incidents
FROM incidents
WHERE resolved_at IS NOT NULL
  AND created_at >= NOW() - INTERVAL '30 days';
```

### Top Failing Devices
```sql
SELECT 
    device_id,
    COUNT(*) as incident_count,
    MAX(d.vendor) as vendor,
    MAX(d.model) as model
FROM incidents i
JOIN devices d USING(device_id)
WHERE created_at >= NOW() - INTERVAL '7 days'
GROUP BY device_id
ORDER BY incident_count DESC
LIMIT 10;
```

## Backup & Restore

### Manual Backup
```bash
docker exec smart-noc-postgres pg_dump -U noc_admin smart_noc > backup_$(date +%Y%m%d).sql
```

### Restore from Backup
```bash
cat backup_20260613.sql | docker exec -i smart-noc-postgres psql -U noc_admin -d smart_noc
```

```sql
-- Find missing indexes
SELECT schemaname, tablename, attname, null_frac, avg_width, n_distinct
FROM pg_stats

CREATE INDEX idx_incidents_device_status_created ON incidents(device_id, status, created_at DESC);
```
